# Tabla 3. Tipología de rituales aplicables a gestión pública

|---|---|---|
| Ingreso | Bienvenida institucional | Socialización de valores públicos |
| Reconocimiento | Ceremonias de mérito | Valoración simbólica del trabajo |
| Rendición de cuentas | Cuenta pública o audiencia | Legitimidad y transparencia |
| Participación | Cabildos o foros ciudadanos | Deliberación democrática |
| Cierre | Cierre de proyectos o programas | Aprendizaje institucional |
