# Metodología de revisión y análisis hermenéutico

Este repositorio documenta un manuscrito de reflexión conceptual. La metodología se basa en revisión bibliográfica, análisis documental y lectura hermenéutica de literatura sobre rituales organizacionales, gestión pública, legitimidad institucional, valor público y cultura organizacional latinoamericana.

No se presentan datos empíricos propios. Las figuras y tablas son dispositivos de síntesis conceptual.

## Enfoque

- Revisión bibliográfica narrativa.
- Análisis hermenéutico-conceptual.
- Integración crítica de literatura organizacional y de administración pública.
- Formalización conceptual del modelo KANA-GP.

## Exclusiones metodológicas

- No es revisión sistemática.
- No incluye encuesta.
- No incluye entrevistas propias.
- No incluye datos estadísticos.
- No incluye base de datos empírica.
